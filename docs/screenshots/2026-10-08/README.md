# App screenshots — 8 October 2026 (UTC)

Seven direct captures from version **3.0.0 (300)**, debug package, on an NX809J
phone. Captured on 9 October in Stockholm (8 October UTC).
These show the implemented interface on a real device, without retouching.

The display was temporarily set to 1080 × 1920 at 400 dpi and then restored to
1216 × 2688 at 520 dpi. Font scale is 1.0. The first six captures use the light
theme; the last shows dark mode. The real status bar is visible. No recording
contents, transcripts, speaker identities, email addresses or payment details
are included. The Home screen shows that speaker-triggered saving is enabled
but still needs a speaker selection; these are the device’s existing settings,
not a new installation’s defaults.
