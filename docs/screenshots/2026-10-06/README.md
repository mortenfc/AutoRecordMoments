# Current app screenshots — 6 October 2026

Six direct captures from a connected NX809J phone running the installed Android
2.0.0 build (version code 200, debug package). These are actual app screens, not
mockups. The installed build was last updated on 6 October 2026; its exact source
commit was not embedded in the captured metadata.

Each image is 1080 × 1920, 24-bit RGB PNG without transparency. Display size and
density were temporarily set to 1080 × 1920 / 400 dpi and restored to the phone's
original 1216 × 2688 / 520 dpi afterwards. Only PNG encoding was converted; UI
content was not retouched. The phone did not apply System UI demo mode, so the
real status bar remains visible. No recordings, transcripts, speaker identities,
account email addresses or payment details are shown.
